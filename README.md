# reaper-band-collab

A [REAPER](https://www.reaper.fm/) extension for bands that record in several home studios.

Each member works on their own instrument in an isolated workspace (re-record, correct timing, add effects) while hearing the rest of the band as the producer currently has it. The producer decides when a member's work goes into the master project, so the master stays safe.

**Status: work in progress.** The design is in [`openspec/changes/reaper-band-collab/`](openspec/changes/reaper-band-collab/) (proposal, design, specs and task list). User documentation in Finnish and English, with installation instructions, will be added here before the first release.
